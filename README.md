概要

未来の特定日時に生成される公開鍵でファイルを暗号化する。その日時が訪れるまでファイルが閲覧されることはない。この技術をより使い易くする目的でこのプロジェクトは始動した。

キーワード：タイムロック暗号化、管理

主な機能
- ファイルのタイムロック暗号化とその復号

管理機能
- 暗号化された日時, 場所, ユーザーの記録
- 復号される日時の確認
- 別の場所から同様の手法で暗号化されたファイルをリストに追加

免責事項
- 閾値委員会の機能に依存しているため復号される保証はできず委員会の規約に同意したものと見なす。

## 🚀 "MyTock" 開発ロードマップ

### Phase 1: コアロジックの構築（CLI基礎）
- **実装機能**:
    
    - `mytock encrypt <file> --duration 1h`: 指定した時間で封印。裏でリストに加えられる。
    - `mytock decrypt <file>`: 復号（時間が早ければエラーを出す）。成功すれば裏でリストから除外される

    リストはSQLiteを使用。

### Phase 2: ローカル管理機能の実装
- **実装機能**:
    - `mytock list`:mytockで作成・追加した暗号化されたファイル一覧を表示。
    - `mytock add <file>`:同手法で作成されたファイルをリストに追加。
    - `mytock config`:mytockに設定されているDorandネットワークを確認。
